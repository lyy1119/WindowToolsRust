# WindowToolsRust

> 用 Rust 写的 Windows 窗口增强小工具 —— 给任意窗口加红框标记、一键置顶、按预设调整分辨率、按进程静音。

一个类似 [WindowTop](https://github.com/WindowTop/WindowTop-App) 的轻量替代品。
界面用纯 Rust 的 `egui` 画，Windows 原生能力走 `windows-rs`，**不注入任何目标进程**。

`v1.0.0` · Windows 10/11 x64 · MIT License

## 功能与特点

### 核心功能

| 功能 | 说明 |
|---|---|
| 🔴 **红框标记** | 给任意窗口套一个红色边框。中间镂空、鼠标完全穿透，不影响正常点击；窗口移动/缩放时红框实时跟随，窗口最小化时自动隐藏，窗口关闭时自动消失 |
| 📌 **窗口置顶** | 一键把窗口钉在最上层 / 取消置顶，可设置「置顶时自动加红框」当作状态指示 |
| 📐 **调整到指定分辨率** | 按预设把窗口调成 1920×1080、1280×720… 预设可在界面里增删改，支持「客户区尺寸」和「整个窗口尺寸」两种口径 |
| 🔇 **按进程静音** | 静音指定窗口所属进程的声音。跨所有播放设备枚举音频会话，先按 PID 精确匹配，匹配不到再按进程名回退匹配 |
| 🖱️ **标题栏右键菜单注入** | 往目标窗口原有的右键（系统）菜单里追加条目：标记红框 / 置顶 / 静音 / 调整分辨率（子菜单列出你的预设），外观和原生菜单一致 |
| 🎯 **窗口拾取** | 快捷键拾取光标下的窗口，或从窗口列表里选 |
| 📥 **托盘常驻** | 关闭窗口默认只隐藏到托盘，程序继续在后台跑；托盘菜单可直接操作 |

### 特点

* **不注入目标进程。** 红框是一个独立的镂空置顶覆盖层窗口；系统菜单点击用低层鼠标钩子捕获。
  不需要往别的进程塞 DLL，不涉及位数匹配，也不会被杀软误报。
* **对「自绘标题栏」的程序也有效。** Firefox、PotPlayer 皮肤模式这类自己画标题栏、
  没有 Windows 系统菜单的程序，置顶 / 红框 / 静音照常可用。
* **快捷键直接作用于当前活动窗口。** 像 WindowTop 一样，切到目标窗口按一下就行，不用先拾取。
* **中文字体自动处理。** 自动从系统字体目录挑选微软雅黑 / 等线 / 黑体等，不会出现方框字。
* **单实例 + 管理员权限自检。** 重复启动只会唤出已有窗口；未提权时界面会提示并给一键提权重启。
* **轻量。** 单个 exe，约 22 MB，无运行时依赖（不需要 .NET / VC++ 运行库）。

## 使用

### 系统要求

* Windows 10 / 11，64 位
* 无运行时依赖，`window-tools-rust.exe` 双击即可运行
* 如需操作**以管理员身份运行的窗口**（如任务管理器），本程序也需要以管理员身份运行

### 获取与编译

从源码编译需要 Rust stable（开发时使用 1.99.0）：

```powershell
git clone https://github.com/lyy1119/WindowToolsRust.git
cd WindowToolsRust
cargo build --release
# 产物: target/release/window-tools-rust.exe
```

Debug 构建会保留控制台窗口并输出日志，方便排查问题：

```powershell
cargo run
```

### 快速上手（3 步）

1. **启动** `window-tools-rust.exe`。程序会显示主界面，同时在托盘里常驻一个图标。
2. **选择目标窗口**：把鼠标移到目标窗口上按 `Ctrl+Alt+P` 拾取。
   （也可以跳过这步 —— 快捷键默认直接作用于**当前活动窗口**。）
3. **操作**：按 `Ctrl+Alt+T` 置顶、`Ctrl+Alt+F` 加红框、`Ctrl+Alt+M` 静音；
   或者在**目标窗口的标题栏上点右键**，菜单底部会多出 `WindowTools:` 开头的条目。

### 快捷键

默认值如下，**全部可以在界面里改**（「全局快捷键」一节，改完点「应用快捷键」）：

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Alt+P` | 拾取光标下的窗口作为目标 |
| `Ctrl+Alt+F` | 红框开 / 关 |
| `Ctrl+Alt+T` | 置顶 / 取消置顶 |
| `Ctrl+Alt+M` | 静音 / 取消静音 |

写法：修饰键在前、主键在最后，例如 `Ctrl+Alt+T`。修饰键可用 `Ctrl` / `Control`、`Alt`、
`Shift`、`Super`（Win 键）；主键可以直接写 `T`，也可以写成 `KeyT`。
**留空表示不注册这个快捷键。**

重新注册时会先注销旧的、再注册新的；如果新快捷键已被别的程序占用，会**自动回滚**到旧快捷键，
不会出现「改坏了就一个快捷键都用不了」。

### 托盘菜单

右键托盘图标：

```text
显示主窗口
拾取光标下的窗口
──────────────
标记红框          [勾选状态]
窗口置顶          [勾选状态]
静音 / 取消静音
──────────────
退出
```

后两项是勾选状态，会跟随实际状态变化。**双击托盘图标**也能唤出主窗口。

### 标题栏右键菜单

在目标窗口的标题栏上点右键，原生菜单底部会多出：

```text
──────────────
WindowTools: 标记红框
WindowTools: 置顶 / 取消置顶
WindowTools: 静音 / 取消静音
WindowTools: 调整到指定分辨率 ▸  ┌ 1920 x 1080（1080P）┐
                                 │ 1280 x 720（720P）  │
                                 └ …                   ┘
```

点击菜单项会以**被点击的那个窗口**为对象执行操作。

> ⚠️ **自绘标题栏的程序**（Firefox、PotPlayer 皮肤模式等）**没有 Windows 系统菜单**，
> 所以无法注入条目 —— 这是系统层面的限制，任何工具都绕不过去（除非注入 DLL）。
> 这类窗口请用快捷键或托盘菜单操作，功能完全一样。

### 设置项

界面「设置」一节：

| 设置项 | 默认 | 说明 |
|---|---|---|
| 红框颜色 | `#E52828` | 取色器直接选 |
| 红框粗细 | 3 px | 1~16 |
| 拾取时自动标记红框 | 开 | `Ctrl+Alt+P` 拾取到窗口后顺手画红框 |
| 置顶时自动标记红框 | 开 | 置顶时自动画红框当作状态提示；**取消置顶时会自动移除这个自动加的红框**（手动标的红框不受影响） |
| 注入标题栏右键菜单 | 开 | 关掉后不再改动任何窗口的系统菜单 |
| 防止重复启动（单实例） | 开 | 已有实例在跑时，再启动只会把它的窗口唤出来 |
| 快捷键作用于当前前台窗口 | 开 | 勾选＝操作当前活动窗口；取消＝只操作界面里拾取的目标 |
| 中文字体文件 | 空 | 留空＝自动挑选；填文件名或绝对路径可换成更小的字体以降低内存，重启生效 |
| 关闭窗口时最小化到托盘 | 开 | 关闭＝隐藏到托盘，退出请用托盘菜单 |

「分辨率预设」一节可以增删改预设（名称 / 宽 / 高），点「保存设置」后会写回配置文件，
并自动刷新标题栏右键菜单里的子菜单。

### 配置文件

```text
%USERPROFILE%\WindowToolsSetting\config.json
```

首次运行时会用内置默认值，保存设置时自动创建。界面底部会显示实际路径。

### 管理员权限

程序启动时会自检权限：

* **已提权**：界面顶部显示绿色的「✓ 已以管理员身份运行」。
* **未提权**：显示橙色提示，并提供「以管理员身份重启」按钮（会弹 UAC）。

为什么需要：如果要操作的目标窗口属于**以管理员身份运行的进程**，而本程序只是普通权限，
那么 `SetWindowPos`、`GetSystemMenu` 等调用都会因为完整性级别不够而失败 ——
表现就是「某些窗口怎么点都没反应」。

## 已知限制

* **静音是「按进程」的，不是「按窗口」的。** Windows 没有按窗口的静音接口，声音本身就是进程级的。
  同一进程的多个窗口会一起静音；进程**当前没有发声**时枚举不到音频会话，界面会给出提示。
* **自绘标题栏的窗口无法注入右键菜单**（原因见上）。
* **UWP / 商店应用**的音频会话可能归属系统进程，静音暂不支持。
* 系统菜单里「子菜单项」的点击捕获依赖鼠标钩子命中测试，个别场景下可能不够灵敏。
* 还没有 exe 图标与版本资源。

## 常见问题

**Q：按快捷键没反应？**
先确认焦点在目标窗口上（快捷键默认作用于当前活动窗口）。如果焦点在本程序自己的界面上，
会退回上一次拾取的目标。界面下方的运行日志每次都会记一行，可以看到具体原因。

**Q：红框没跟着窗口走？**
红框跟随用的是「WinEvent 事件钩子 + 界面线程轮询」双保险。如果仍有异常，
检查是否存在高 DPI 缩放 / 多显示器混合 DPI 的情况，并确认程序是最新版本。

**Q：某些窗口置顶无效？**
多半是该窗口以管理员权限运行而本程序没有。点界面顶部的「以管理员身份重启」。

**Q：怎么彻底退出？**
托盘图标右键 →「退出」。直接关窗口只会隐藏到托盘。

## 技术栈

| 用途 | 依赖 |
|---|---|
| Windows 原生能力 | [`windows`](https://crates.io/crates/windows) (windows-rs) 0.62 |
| 界面 | [`eframe`](https://crates.io/crates/eframe) / egui 0.36 |
| 托盘 | [`tray-icon`](https://crates.io/crates/tray-icon) 0.26 |
| 全局快捷键 | [`global-hotkey`](https://crates.io/crates/global-hotkey) 0.8 |
| 配置 | `serde` + `serde_json` |

**所有 `unsafe` 和裸句柄都集中在 `src/win/` 目录**，界面 / 托盘 / 热键 / 状态模块完全不碰 Win32。

```text
src/
├── main.rs            入口
├── app.rs             eframe App：串联托盘、热键、界面、轮询
├── ui.rs              egui 界面
├── tray.rs            托盘图标与菜单
├── hotkey.rs          全局快捷键
├── fonts.rs           中文字体加载
├── config.rs          配置读写
├── state.rs           全局共享状态
└── win/               ← 仅此目录允许 unsafe
    ├── mod.rs         句柄转换
    ├── dpi.rs         DPI 感知
    ├── window.rs      窗口枚举 / 信息 / 置顶 / 调整大小
    ├── frame.rs       红框覆盖层
    ├── audio.rs       按进程静音（WASAPI）
    ├── sysmenu.rs     系统菜单注入与点击捕获
    ├── privilege.rs   管理员权限检测与提权
    ├── single_instance.rs  单实例
    └── actions.rs     业务动作（所有入口的公共实现）
```
